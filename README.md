# Охранная сирена и аналоговый регулятор

Уроки 8–9 по робототехнике (Arduino Uno): параллельная работа света и звука, потенциометр и аналоговый вход `analogRead`.

**Открыть уроки:** https://nurdauletizm.github.io/arduino-sirena-regulyator/

На странице: теория с интерактивными примерами, монтажная и принципиальная схемы, 3D-модель стенда и симулятор, который выполняет код скетчей и подсвечивает текущую строку. В каждом уроке 4 задания, таблица сборки, разбор кода, частые ошибки, вопросы и план урока.

Скетчи для Arduino IDE — в папке [`arduino`](arduino): 12 штук, все компилируются для Arduino Uno.

Arduino — товарный знак его правообладателя. Плата Arduino Uno на схемах нарисована для учебных целей.
